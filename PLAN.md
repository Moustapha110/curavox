## 1. Next.js 16 / Tailwind v4 / lint gotchas (verified against installed docs and packages)

**Routing / props**
- `params` and `searchParams` are Promises. Always: `const { id } = await params; const sp = await searchParams;`. Type with the global helpers (no import): `export default async function Page(props: PageProps<'/patient/[id]'>)`, `LayoutProps<'/physician'>`, `RouteContext<'/api/x/[id]'>`. These types are generated by `next dev`/`next build`/`next typegen`; if TS complains before first build, fall back to explicit `{ params: Promise<{ id: string }>; searchParams: Promise<Record<string, string | string[] | undefined>> }`.
- Reading `searchParams` in a page opts that route into dynamic rendering. That is what we want for `/patient/[id]`. Do NOT use `useSearchParams` in a client component for the patient page (a statically rendered page calling it without `<Suspense>` fails `next build`). Read on the server and pass props down.
- `metadata` / `viewport` exports only in Server Components. `themeColor` goes in `export const viewport: Viewport = { themeColor: '#050505' }`, NOT in `metadata`.
- Route Handlers: `src/app/api/<name>/route.ts`, `export async function POST(req: Request)`, return Web `Response`/`Response.json()`. No `page.tsx` may sit next to a `route.ts`. POST handlers are never cached.
- Next 16 no longer overrides `scroll-behavior` on navigation. Do not set `scroll-behavior: smooth` globally (it would fight Lenis).
- Turbopack is the default bundler for dev and build; no webpack config. Importing CSS from node_modules inside any component in `app/` is allowed (`import "lenis/dist/lenis.css"`).
- `next/dynamic` with `ssr: false` is only allowed inside Client Components; we do not need it anywhere.
- `LayoutProps<"/">` is already used in the scaffold layout; keep it.
- `cacheComponents` is not enabled in `next.config.ts`; leave it off.

**Client/server boundary**
- `"use client"` at the very top (above imports) of every file that uses hooks, event handlers, browser APIs, GSAP, Lenis, framer-motion, react-qrcode-logo (class component with canvas), or `window`. Once a file is a client module, everything it imports is bundled for the client; do not import `openai`, `src/lib/system-prompt.ts` or anything reading `process.env.OPENAI_API_KEY` from a client file. `src/data/metformin.ts`, `src/lib/companion.ts`, `src/lib/constants.ts`, `src/lib/types.ts` are isomorphic and safe on both sides.
- Server pages may render client components and pass only serializable props (strings, numbers, plain objects).
- Env vars without `NEXT_PUBLIC_` are empty strings in the browser. Only read `OPENAI_API_KEY` inside route handlers.

**Tailwind v4 (4.3.3)**
- `globals.css` starts with `@import "tailwindcss";`. No `tailwind.config.js`, no `@tailwind base/components/utilities`.
- Design tokens go in `@theme { ... }` (or `@theme inline` for values referencing CSS vars set elsewhere, e.g. next/font variables). Namespaces: `--color-*` -> `bg-/text-/border-*`, `--font-*` -> `font-*`, `--animate-*` -> `animate-*`, `--ease-*`, `--shadow-*`. `@keyframes` may be declared inside `@theme` next to the `--animate-*` token.
- Do not name a color token `teal` or `amber` (collides with built-in palettes). Use `--color-brand` (#00D4AA), `--color-gold` (#F5B94A), `--color-ink` (#050505).
- Custom reusable classes: `@utility glass { ... }` (works with variants) or plain classes inside `@layer components`.
- Arbitrary values are supported (`perspective-[1200px]`, `[transform-style:preserve-3d]`, `[backface-visibility:hidden]`), but for 3D-heavy elements prefer inline `style` or dedicated CSS classes in globals.css to keep GSAP's transforms authoritative (GSAP writes `transform` inline; do not also apply Tailwind transform utilities to GSAP-animated elements).
- Dark theme is forced: `<html lang="en" className="dark">` plus `color-scheme: dark` on `:root`; no `prefers-color-scheme` branching.

**next/font**
- `import { Inter, Space_Grotesk } from "next/font/google"`; both are variable fonts, so no `weight` needed. Use the `variable` option (`--font-inter`, `--font-space-grotesk`) and put both class names on `<html>`; map them in `@theme inline { --font-sans: var(--font-inter); --font-display: var(--font-space-grotesk); }`. Use `subsets: ["latin", "latin-ext"]` (Spanish/French accents).

**ESLint 9 + eslint-plugin-react-hooks 7.1.1 (React Compiler rules are ON via eslint-config-next)**
These rules will fail `npm run lint` if violated:
- `react-hooks/set-state-in-effect`: no synchronous `setState(...)` directly in a `useEffect` body. Pattern: `useEffect(() => { void startGreeting(); }, [])` where `startGreeting` is async and sets state after an `await`, or set state inside subscriptions/callbacks. Never do `useEffect(() => setMounted(true), [])`.
- `react-hooks/refs`: never read or write `ref.current` during render; only inside effects, `useGSAP`, or event handlers.
- `react-hooks/purity`: no `Math.random()`, `Date.now()`, `crypto.randomUUID()`, `new Date()` during render (including `useMemo`/`useState` initializers). Generate ids/timestamps in event handlers or effects. For particle positions, compute inside the effect that owns the canvas.
- `react-hooks/immutability`: never mutate state/props objects; always build new arrays/objects.
- `react-hooks/static-components`: never define a component inside another component's body (no `const Icon = () => ...` inside render).
- `react-hooks/exhaustive-deps` is a warning; keep deps honest, and for one-shot effects use refs for guards (`greetedRef`).

**TypeScript**
- `SpeechRecognition` (the constructor / `SpeechRecognitionEvent`) is NOT declared in the installed `lib.dom.d.ts` (only `SpeechRecognitionResult`/`Alternative`/`ResultList` are). Declare a minimal ambient interface in `src/types/speech.d.ts` (see below).
- `lz-string` ships its own typings, so `@types/lz-string` is redundant but harmless. If a duplicate-declaration error ever appears, `npm rm @types/lz-string`.

**Cleanup**

## 2. Library API notes (from installed versions)

### Lenis 1.3.26
```ts
import Lenis from "lenis";                 // core class
import "lenis/dist/lenis.css";             // required CSS
```
We use the core class + GSAP ticker sync:
```ts
const lenis = new Lenis({ lerp: 0.08, smoothWheel: true, syncTouch: false, autoRaf: false, anchors: true });
lenis.on("scroll", ScrollTrigger.update);
const tick = (time: number) => lenis.raf(time * 1000);   // gsap ticker gives seconds; lenis.raf wants ms
gsap.ticker.add(tick);
gsap.ticker.lagSmoothing(0);
// cleanup:
gsap.ticker.remove(tick); lenis.destroy();
```
Options verified: `lerp`, `duration`, `smoothWheel`, `syncTouch`, `syncTouchLerp`, `autoRaf`, `anchors`, `stopInertiaOnNavigate`, `respectReducedMotion` (default true). Methods: `raf(time)`, `on("scroll", cb)`, `off`, `start()`, `stop()`, `scrollTo(target, opts)`, `destroy()`.

### GSAP 3.15 + @gsap/react 2.1.2
```ts
import { gsap } from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
import { useGSAP } from "@gsap/react";
gsap.registerPlugin(ScrollTrigger, useGSAP);
```
`useGSAP(callback, { scope: ref, dependencies?: [], revertOnUpdate?: boolean })` returns `{ context, contextSafe }`. It is a `useLayoutEffect` (falls back to `useEffect` on the server) and auto-reverts every tween/ScrollTrigger/matchMedia created inside the callback on unmount. Selectors inside the callback are scoped: `gsap.utils.toArray<HTMLElement>("[data-stat]")` only matches inside `scope`. Wrap event-handler-created tweens with `contextSafe`.
ScrollTrigger statics verified: `ScrollTrigger.update`, `.refresh()`, `.config({ ignoreMobileResize: true })`, `.normalizeScroll()`, `gsap.matchMedia()`.

### framer-motion 13.4.0

```ts
import { motion, AnimatePresence, useMotionValue, useSpring, useTransform, useInView, useReducedMotion, MotionConfig, useScroll } from "framer-motion";
```

## 4. Landing page animation architecture

**Global setup**
- `SmoothScroll` (Lenis, `lerp .08`, native root scroll) + GSAP ticker sync; `ScrollTrigger.config({ ignoreMobileResize: true })`; `ScrollTrigger.refresh()` after fonts/load. Pinned sections use `pin: true, pinSpacing: true, anticipatePin: 1, invalidateOnRefresh: true, scrub: 1` (hero uses `scrub: true`). Each section `start: "top top"`. Each section's tail (last 15-20% of its timeline) fades/moves its content out while the next fades in, so the page reads as one continuous motion.
- 3D: containers whose children rotate in 3D get `perspective: 1200px` (style) and children `transform-style: preserve-3d; backface-visibility: hidden; will-change: transform`. Use `transformPerspective` when a child needs its own vanishing point.
- All section code inside `gsap.matchMedia()`: `mm.add({ motionOk: MOTION_OK_QUERY, isDesktop: "(min-width: 768px)", isMobile: "(max-width: 767px)" }, (ctx) => { const { motionOk, isDesktop } = ctx.conditions!; if (!motionOk) return; ... })`. Reduced-motion users get static visible sections.
- Persistent `AmbientOrb` (fixed) driven by one page-length scrubbed timeline: the hero's orb visibly travels through every section.

**Section 1 Hero** — entrance timeline on load: per-letter `rotateX -80 -> 0`, `y 60 -> 0`, `opacity 0 -> 1`, `stagger .04`, `ease: "expo.out"`, `duration 1.1`; badge/subtitle/CTAs `y 24 -> 0` at `-=.6`. Scroll: pin, `end: "+=90%"`, `scrub: true`: title `{ scale: .82, y: -60, rotateX: 18, opacity: 0, ease: "none" }`, subtitle + CTAs `{ y: -30, opacity: 0, stagger: .1 }`, scroll cue `{ opacity: 0 }`.

**Section 2 Problem** — pinned, `end: "+=260%"`, container `perspective 1200px`. Timeline labels 0-10:
- 0: heading `from { y: 40, opacity: 0 }`; `[data-stat-bg]` `to { yPercent: -35 }` across the whole timeline (parallax).
- 1, 3.5, 6: each stat card `from { z: -700, opacity: 0, rotateY: (i===0 ? 24 : i===2 ? -24 : 0), x: (i===0 ? -80 : i===2 ? 80 : 0) }` `to { z: 0, rotateY: 0, x: 0, opacity: 1, duration: 1.6, ease: "power2.out" }`; counter proxy tween with `snap` at the same position; caption `from { y: 20, opacity: 0 }` at `+=.3`. Faint duplicate number behind each at `translateZ(-200px)` opacity .15 moving at half speed.
- 8.5-10: cards `to { y: -80, z: -300, opacity: 0, stagger: .08 }`, heading `to { opacity: 0 }`.

**Sections 3+4 PhoneStage** — one `useGSAP` with `ScrollTrigger { pin: true, start: "top top", end: "+=520%", scrub: 1, anticipatePin: 1 }`. `[data-phone-wrap]` in a `perspective: 1600px` column; `Phone3D` is `[data-phone]`. Timeline 0-20:

## 5. Chat streaming contract

**Request** `POST /api/chat`, JSON:
```json
{ "messages": [{ "role": "user"|"assistant", "content": "..." }], "drug": "metformin", "language": "es"|"fr"|"en", "doctorName": "Dr. Martinez", "patientName": "María" }
```
Server: (1) if `!process.env.OPENAI_API_KEY` -> `Response.json({ error: "OpenAI API key not configured. Add OPENAI_API_KEY to .env.local and restart the dev server." }, { status: 503 })`. (2) Validate: `drug` in `DRUG_DATA`, `isLanguageCode(language)`, `messages` array of `{role in ["user","assistant"], content string ≤ 2000 chars}`; keep last `MAX_HISTORY_MESSAGES`; 400 on failure. (3) If `messages.length === 0` push `{ role: "user", content: GREETING_TRIGGER }`. (4) `system = buildSystemPrompt(getDrugContextString(getDrug(drug)), LANGUAGE_NAMES[language], doctorName, patientName)`. (5) Stream via `ReadableStream`, `Content-Type: text/plain; charset=utf-8`, `Cache-Control: no-cache, no-transform`, `X-Accel-Buffering: no`. If OpenAI throws before streaming -> `Response.json({ error: friendlyMessage(err) }, { status: 502 })` (401 -> "Invalid OpenAI API key", 429 -> "Rate limited, try again"). If it throws mid-stream, close the stream.

**Response** `200`: raw UTF-8 text chunks (no SSE framing). Non-200: JSON `{ error }`.

**Client reading (PatientChat)**
```ts
async function send(userText: string | null) {                // null = greeting
  const history = messages.filter(m => m.status !== "error").map(({ role, content }) => ({ role, content }));
  const userMsg = userText ? { id: crypto.randomUUID(), role: "user", content: userText, status: "done", createdAt: Date.now() } : null;
  const assistantId = crypto.randomUUID();
  setMessages(prev => [...prev, ...(userMsg ? [userMsg] : []), { id: assistantId, role: "assistant", content: "", status: "streaming", createdAt: Date.now() }]);
  setIsStreaming(true);
  const controller = new AbortController(); abortRef.current = controller;
  try {
    const res = await fetch("/api/chat", { method: "POST", headers: { "Content-Type": "application/json" }, signal: controller.signal,
      body: JSON.stringify({ messages: [...history, ...(userMsg ? [{ role: "user", content: userText }] : [])], drug, language, doctorName, patientName }) });
    if (!res.ok || !res.body) { const { error } = await res.json().catch(() => ({ error: strings.errorGeneric })); if (res.status === 503) setApiAvailable(false); patch(assistantId, { content: userText ? error : strings.fallbackGreeting(drugName, doctor), status: "error" }); return; }
    const reader = res.body.getReader(); const decoder = new TextDecoder(); let acc = "";
    for (;;) { const { done, value } = await reader.read(); if (done) break; acc += decoder.decode(value, { stream: true }); patch(assistantId, { content: acc }); }
    patch(assistantId, { status: "done" });
  } catch (e) { if ((e as Error).name !== "AbortError") patch(assistantId, { status: "error", content: strings.errorGeneric }); }
  finally { setIsStreaming(false); abortRef.current = null; }
}
```
`patch` = `setMessages(prev => prev.map(m => m.id === id ? { ...m, ...partial } : m))`. `LoadingDots` renders inside the assistant bubble while `status === "streaming" && content === ""`. Stop button calls `abortRef.current?.abort()`.

**Greeting on load**: `useEffect(() => { if (greetedRef.current) return; greetedRef.current = true; void send(null); }, [])`. The ref guard survives StrictMode's double-invoke; `send` is async so no synchronous setState in the effect body. When the API is unavailable (503) the assistant bubble shows the localized static fallback greeting and an amber "Live AI unavailable, demo mode" notice appears under the header.

**Voice input**: `useSpeechRecognition(LANGUAGE_MAP[lang].speechCode)` with codes `es-ES`, `fr-FR`, `en-US`. Interim results stream into the textarea; final result replaces it and auto-sends. Unsupported browsers hide the mic button.

**TTS playback**: speaker button on each assistant bubble with `status === "done"` -> `speak(message.id, message.content)` -> `POST /api/tts { text, language }` -> `audio/mpeg` blob -> `Audio` play. States: loading, playing (click to stop), error. Blob URLs cached per message.

## 6. Risks and decisions

- **SSR safety**: Lenis, GSAP ScrollTrigger, framer-motion, react-qrcode-logo, Web Speech and `Audio` only touched inside `"use client"` files and inside effects/handlers. Never access `window` in render.
- **Hydration**: no random ids, dates, or `window` reads in render. Dashboard timestamps are fixed ISO strings. Speech `supported` uses `useSyncExternalStore` with a `false` server snapshot.
- **Lenis + pinning**: Lenis in root mode keeps native scroll on `<html>`, so ScrollTrigger pins work without `scrollerProxy`. Do not put `overflow: hidden`/`height: 100%` on `body`. Do NOT wrap Lenis around the chat page.
- **Reduced motion**: `gsap.matchMedia` gates every scroll animation; Lenis `respectReducedMotion` default; framer `MotionConfig reducedMotion="user"`; CSS animations disabled under the media query. Content remains visible.
- **Mobile performance**: few backdrop-filter layers, reduce blur under `md:`, `will-change: transform` only on animated nodes, `syncTouch: false`, `ignoreMobileResize`, `100dvh` for the chat, input font-size 16px.
- **Pin spacing**: `+=520%` on the phone stage; tune down (`+=400%`) if it feels slow. `ScrollTrigger.refresh()` after fonts load.
- **Missing `OPENAI_API_KEY`**: routes return 503 JSON; client degrades to a static localized greeting plus a "demo mode" notice; landing and physician portal never touch OpenAI. OpenAI client constructed inside handlers.
- **URL format**: canonical patient URL is `/patient/<id>?c=<lz>`; plain `?drug=&lang=&doctor=&name=` also decodes.
- **Physician auth** is client-side `sessionStorage` (demo only); state this in the UI hint and README.
- **React Compiler lint rules** are on: avoid setState in effect bodies, ref reads in render, `Math.random`/`Date.now` in render, inline component definitions. Run `npm run lint` and `npm run build` after each phase.
- **Web Speech availability**: Chrome/Edge/Safari only; button hidden elsewhere.
- **Bundle boundaries**: never import `openai` or `system-prompt.ts` from client files.
